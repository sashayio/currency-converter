# World Prices — Конвертер валют и криптовалют

Удобный, быстрый и адаптивный веб-конвертер мировых валют и криптовалют с возможностью экспорта результатов в PNG.

**Демо онлайн (GitHub Pages):** [https://sashayio.github.io/world-prices/](https://sashayio.github.io/world-prices/)

---

## Возможности

- 💱 **Популярные и мировые валюты:** RUB, USD, EUR, GBP, CNY, JPY, CHF, TRY, валюты СНГ (BYN, KZT, UAH, UZS, GEL, AZN, AMD и др.) и другие мировые валюты.
- 🪙 **Криптовалюты в реальном времени:** Bitcoin (BTC), Ethereum (ETH), Tether (USDT), Solana (SOL), TON, BNB, XRP, Dogecoin и др.
- ⚡ **Актуальные курсы без задержек:**
  - Фиатные курсы обновляются каждый час напрямую с открытого рынка (Open ExchangeRate-API).
  - Криптовалютные котировки обновляются в реальном времени (Binance Spot API + CoinGecko fallback).
  - 100% бесплатно, без ключей API и без ограничений на запросы.
- 🖥️ **Полная адаптивность:**
  - Удобный компактный вид на мобильных устройствах.
  - Просторная многоколоночная сетка (Grid) на ПК и планшетах — все выбранные валюты видны сразу без бесконечной прокрутки.
- 📸 **Экспорт в PNG:**
  - Генерация стильной карточки с выбранными курсами и флагами (включая флаг EUR и крипто-иконки).
- 💾 **Сохранение настроек:**
  - Автоматическое сохранение выбранных валют и суммы в LocalStorage.

---

## Запуск локально

Проект не требует сборщиков и зависимостей. Достаточно открыть `index.html` в любом браузере:

```bash
# Через локальный сервер (например, Python или Node.js):
python -m http.server 8000
# или просто открыть index.html
```
