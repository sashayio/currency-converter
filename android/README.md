# World Prices — Нативное Android-приложение (Kotlin + Jetpack Compose)

Автономное, легкое мобильное приложение для мгновенной конвертации мировых валют и криптовалют с поддержкой офлайн-режима, кастомных курсов, анимированного онбординга и экспорта в PNG.

---

## 🚀 Пошаговая инструкция по запуску на вашем телефоне

### Шаг 1. Установка Android Studio (если еще не установлена)
1. Скачайте официальную бесплатную среду разработки **Android Studio**:  
   👉 [https://developer.android.com/studio](https://developer.android.com/studio)
2. Запустите скачанный инсталлятор. Следуйте подсказкам мастера установки (*Next → Next*).
3. При первом запуске Android Studio предложит скачать стандартные компоненты SDK — согласитесь (*Standard Installation*).

---

### Шаг 2. Открытие проекта в Android Studio
1. Запустите Android Studio.
2. На стартовом экране нажмите кнопку **Open** (или в верхнем меню: `File → Open...`).
3. В окне выбора файлов перейдите в папку:
   ```text
   h:\projects\world-prices\android
   ```
   *(⚠️ Важно: открывайте именно подпапку `android`, а не корень всего репозитория).*
4. Нажмите **OK**.
5. Android Studio откроет проект и автоматически запустит первичную синхронизацию Gradle (*Gradle Sync*). В правом нижнем углу появится сообщение: `BUILD SUCCESSFUL` или `Gradle sync finished`.

---

### Шаг 3. Подключение вашего телефона и запуск

#### Вариант А: Запуск по USB-проводу (самый простой и надежный)
1. **Включите режим разработчика на телефоне**:
   - Откройте *Настройки* телефона → *О телефоне* (или *Сведения о телефоне*).
   - Найдите пункт **Номер сборки** (*Build number*) и быстро нажмите на него **7 раз подряд**.
   - Телефон напишет: *"Вы стали разработчиком!"*.
2. **Включите отладку по USB**:
   - В *Настройках* перейдите в появившийся раздел *Для разработчиков* (или *Система → Для разработчиков*).
   - Включите переключатель **Отладка по USB** (*USB Debugging*).
3. **Подключите телефон к компьютеру**:
   - Соедините телефон с ПК обычным USB-кабелем.
   - На экране телефона появится запрос: *«Разрешить отладку по USB с этого компьютера?»*. Поставьте галочку *«Всегда разрешать с этого компьютера»* и нажмите **Разрешить**.
4. **Запуск**:
   - В верхней панели Android Studio в выпадающем списке устройств вы увидите модель вашего телефона (например, *Samsung Galaxy...*, *Xiaomi...*, *Pixel...*).
   - Нажмите зелёную кнопку **▶ Run** (или нажмите `Shift + F10`).
   - Проект скомпилируется, приложение автоматически установится и сразу запустится на экране вашего смартфона!

#### Вариант Б: Запуск по Wi-Fi без проводов (Android 11+)
1. Убедитесь, что компьютер и телефон подключены к одной Wi-Fi сети.
2. В меню *Для разработчиков* на телефоне включите **Беспроводная отладка** (*Wireless debugging*).
3. В верхней панели Android Studio в списке устройств нажмите **Pair Devices Using Wi-Fi**.
4. Наведите камеру телефона на показанный QR-код. Телефон подключится, после чего нажмите **▶ Run**.

#### Вариант В: Сборка установочного файла `.APK`
Если вы хотите получить готовый установочный файл и переслать его себе в Telegram или мессенджер:
1. В верхнем меню Android Studio нажмите:
   ```text
   Build → Build Bundle(s) / APK(s) → Build APK(s)
   ```
2. Через минуту в правом нижнем углу Android Studio появится всплывающее уведомление:
   > *APK(s) generated successfully for 1 module.*
3. Нажмите на синюю ссылку **locate** в этом уведомлении.
4. Откроется папка с готовым файлом:
   ```text
   android/app/build/outputs/apk/debug/app-debug.apk
   ```
5. Отправьте этот файл себе на телефон и установите в один клик!

## 📱 Что умеет мобильное приложение

- **Анимированный онбординг при первом открытии**:
  - Слайд 1: Орбитальная плавная анимация валют и криптовалют в реальном времени.
  - Слайд 2: Демонстрация установки своих курсов и работы в авиарежиме (офлайн).
  - Слайд 3: Быстрый выбор вашей базовой валюты и целевых валют прямо на слайде с кнопкой *«Начать 🚀»*.
- **50+ мировых валют и криптовалют**:
  - Популярные фиатные валюты (RUB, USD, EUR, GBP, CNY, TRY, JPY и др.).
  - Страны СНГ и соседи (BYN, KZT, UAH, UZS, GEL, AMD, AZN, KGS, TJS, MDL).
  - Криптовалюты (BTC, ETH, USDT, SOL, TON, BNB, XRP, ADA, DOGE, DOT, LTC, TRX).
- **Свои курсы обмена (Custom Rates)**:
  - Нажатие на карточку валюты открывает удобный модальный расчет.
  - Двунаправленный ввод: меняете `1 USD = 96 RUB` — автоматически пересчитывается `1 RUB = 0.0104 USD`.
  - Ориентир на рыночный курс, кнопка «Взять рыночный» и «Сбросить».
  - Живой предпросмотр расчета для текущей суммы.
  - Карточки со своим курсом выделяются специальным золотистым бейджем «Свой».
- **Управление списком и порядок**:
  - Кнопки перемещения вверх/вниз для изменения порядка карточек.
  - Быстрое удаление ненужной валюты и кнопка добавления новой.
- **Офлайн-режим**:
  - Все загруженные курсы надежно кэшируются через `Jetpack DataStore`. Приложение моментально открывается и считает даже без интернета (например, в самолете или за границей).
- **Экспорт в картинку (Share)**:
  - Иконка «Поделиться» в шапке генерирует стильную карточку-чек высокого разрешения и вызывает системное меню Android (можно отправить в Telegram, WhatsApp или сохранить в галерею).
- **Темы и языки**:
  - Автоматическая, светлая и темная тема.
  - Русский и английский языки.
- **Лайв-сканер ценников и валют (Camera OCR)**:
  - Сканирование ценников, чеков и сумм прямо через камеру смартфона в режиме реального времени.
  - Автоматическое распознавание валют ($, €, £, ₽, ₺, ₸, AED и др.) и умная фильтрация цен.
  - Мгновенный пересчет во все выбранные целевые валюты прямо поверх живого видеопотока.
  - Просмотр карточек валют в горизонтальной карусели или переключение в полный вертикальный список для любого количества валют.
  - Кнопка фиксации кадра (Freeze), включение фонарика и перенос распознанной суммы в основной конвертер в один клик.
- **Поддержка автора**:
  - Быстрая ссылка на «Купить автору кофе» прямо в меню и подвале.

## 🛠 Архитектура и стек

- **Язык**: Kotlin 2.0+
- **Интерфейс**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM (ViewModel + StateFlow + Repository)
- **Сканер**: CameraX (Preview + ImageAnalysis) + Google ML Kit Text Recognition
- **Хранилище**: AndroidX DataStore Preferences
- **Сеть**: OkHttp 4.12 + Kotlinx Serialization
- **Минимальная версия Android**: Android 7.0 (API 24) — поддерживается 99%+ всех устройств
